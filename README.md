# 盲盒校园：暗夜探险

一款**纯音频驱动**的无障碍主题互动游戏。戴上耳机、屏幕全黑，玩家只能靠听和说走完一段校园路。

> 与其告诉玩家盲道很重要，不如让他在黑暗里自己走一次。

## 现状

项目初始化于 2026-11-20，当前为骨架阶段，代码尚未入库。
中期检查（11-26）目标：交付**场景 1** 的 100 秒可玩切片。
游园会目标：3 个场景、单局约 5 分钟完整版。

## 核心机制

玩家全程只能依赖 AI 的耳朵和嘴——这正是视障者面对信息世界的日常。

| 层 | 实现 |
| --- | --- |
| 空间音频 | Web Audio `PannerNode`（HRTF），靠方位与材质判断环境 |
| 语音识别 | 浏览器 `webkitSpeechRecognition`，锁定 12 条指令 |
| 意图理解 | 本地规则 + 同义词表，**三态置信**：直接执行 / 回述确认 / 拒答降级 |
| 语音合成 | 构建期全量预渲染（edge-tts 转 mp3），运行时零延迟 |

**有意不用大模型做意图理解**：实测延迟 1.8 秒且依赖网络，5 分钟一局里每句话多等 2 秒就毁掉沉浸感，现场还没有可靠 wifi。
把"能听懂任何话"换成"听不懂就说不懂"，这个取舍要写进《AI 使用说明》。

## 三个必须出现的判断瞬间

1. **拒答**：左侧没有告示牌 → "我这边没有可读的告示牌。你正前方有一块，要读吗？"
2. **回述确认**：置信度不足 → "你是说，向左走吗？"
3. **降级**：连续两次未识别 → "这里有点吵。可以按 1/2/3，或者直接打字。"

## 环境

- Node.js（Vite + TypeScript）
- Python 3.12（仅用于 `tools/tts_build.py` 预渲染台词）
- 浏览器：桌面 Chrome / Edge 优先，Android Chrome 次之，iOS 尽力支持
