# 盲盒校园：暗夜探险

一款**纯音频驱动**的无障碍主题互动游戏。戴上耳机、屏幕全黑，玩家只能靠听和说走完一段校园路。

> 与其告诉玩家盲道很重要，不如让他在黑暗里自己走一次。

## 现状

项目初始化于 2026-11-20。截至 2026-11-24：**T0–T7 已全部合并，场景 1 可以从头玩到尾**
（开始 → 耳机检查 → 30 秒校准 → 行走/敲杖/读牌/绕行 → 到达 → 结算）。

| 能做的 | 还差的 |
| --- | --- |
| 场景 1 完整通关（90–110 秒） | 场景 2、3（只有设计位） |
| 语音 12 指令 + 三态置信 | Android / iOS 真机未测 |
| 27 条台词预渲染、断网可播 | 噪音环境数据、真人试听 |
| 四屏界面 + 无障碍 + 键盘降级 | 演示视频、展板、承诺书 |

中期检查（11-26）目标：交付**场景 1** 的 100 秒可玩切片——已达到。
游园会目标：3 个场景、单局约 5 分钟完整版。

交付材料：`docs/作品说明.md`、`docs/ai-usage.md`、`docs/venue-setup.md`、`materials/README.md`。

## 快速开始

**不需要 `npm install`，没有构建步骤。**

```bash
# 任选一种方式起本地静态服务器
python -m http.server 8000
npx --yes serve . -l 8000
```

然后浏览器打开 **http://localhost:8000**

> **必须用 `localhost`，不要双击 HTML 文件。** 麦克风权限只在安全上下文可用，
> `localhost` 算安全上下文，`file://` 不算。做语音功能一定会踩这个坑。

## 技术栈

**原生 ES 模块 + 浏览器原生 API，零运行时依赖，无构建步骤。**

这是刻意的选型，不是省事：

| 理由 | 说明 |
| --- | --- |
| 现场必须离线可用 | 游园会草坪的网络不可靠。零依赖意味着现场没有任何东西会加载失败 |
| 多人并行不会卡在安装 | 没有 `package.json` 与 `node_modules`，不存在依赖冲突和安装失败 |
| 少一层调试对象 | 空间音频是核心机制，中间垫一层兼容层会让"声音不对"变得难以归因（详见 `docs/references.md`） |

> 本文档原写「Vite + TypeScript」。在 T0 阶段修正为原生 ES 模块 + JSDoc：
> TypeScript 的类型收益可以用 JSDoc 得到，但构建步骤会同时牺牲「现场直接可跑」
> 和「新人零配置上手」两个更重要的性质。

选型调研与取舍过程见 **docs/references.md**。

## 核心机制

玩家全程只能依赖 AI 的耳朵和嘴——这正是视障者面对信息世界的日常。

| 层 | 实现 |
| --- | --- |
| 空间音频 | Web Audio `PannerNode`（HRTF），靠方位与材质判断环境 |
| 语音识别 | 浏览器 `webkitSpeechRecognition`，锁定 12 条指令 |
| 意图理解 | 本地规则 + 同义词表，**三态置信**：直接执行 / 回述确认 / 拒答降级 |
| 语音合成 | 构建期全量预渲染（edge-tts 转 mp3），运行时零延迟 |

**有意不用大模型做意图理解**：实测延迟 1.8 秒且依赖网络，5 分钟一局里每句话多等 2 秒就毁掉沉浸感，现场还没有可靠 wifi。
把"能听懂任何话"换成"听不懂就说不懂"，这个取舍会写进《AI 使用说明》。

## 三个必须出现的判断瞬间

1. **拒答**：左侧没有告示牌 → "我这边没有可读的告示牌。你正前方有一块，要读吗？"
2. **回述确认**：置信度不足 → "你是说，向左走吗？"
3. **降级**：连续两次未识别 → "这里有点吵。可以按 1/2/3，或者直接打字。"

## 一条来自实测的设计约束

**正后方不放需要玩家分辨的声源。**

实测确认人耳分不出正前与正后（混淆锥现象），完整记录与三条设计改动见
**docs/test-log.md 的 T-001**。因此：

- 所有定位声源限制在**前向半平面**
- 敲杖探测只覆盖**前向 ±45° 锥形**（与真实盲杖一致）
- 需要表达"身后"时改用**语义**（AI 直接说"在你右后方有人"），不依赖声像
- 因此必须提供**30 秒方位校准页**——空间音频的个体差异极大

## 目录结构

```
index.html              唯一入口，统一 import 所有模块
src/
  main.js               装配入口：只做接线，不含业务逻辑
  core/                 【已冻结】bus.js 事件总线 / loop.js 固定步长循环
                        vec.js 几何工具 / contracts.js 接口契约
  audio/                T1 空间音频引擎
  world/                T2 移动 / 碰撞 / 场景加载
  speech/               T4 语音识别、T5 台词播放
  nlu/                  T4 意图解析
  ui/                   T6 屏幕与无障碍
  game/                 T7 任务判定与单局结算
content/                关卡数据、台词表、意图测试用例
assets/                 音频素材
tools/                  tts_build.py 台词预渲染
docs/                   开发文档（见下）
spike/                  技术验证页（一次性工具，双击即可运行）
```
