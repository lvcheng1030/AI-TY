# 现场运行方案

> 目标：草坪上、没有 wifi、只有一台笔记本和一副耳机，也能稳定跑 5 分钟。
> 更新：2026-11-24

## 一、设备清单

| 项 | 数量 | 说明 |
| --- | --- | --- |
| 封闭式耳罩耳机 | 2 | 草坪嘈杂，入耳式压不住环境音；备一副防坏 |
| 笔记本 | 1 | 现场起本地服务，不依赖任何网络 |
| 备用手机 | 1 | 主设备故障时顶上（Chrome，用手机热点或本机服务需另测） |
| 充电宝 | 1 | 笔记本续航兜底 |
| U 盘 | 1 | 整个仓库离线包，含 `assets/voice/` |
| 插排 / 延长线 | 1 | 草坪取电 |
| 湿巾 / 耳罩套 | 若干 | 多人轮流戴耳机 |

## 二、开场前 10 分钟：把服务起起来

```bash
cd AI-TY

# 有 Python：
python -m http.server 8000

# 没 Python、有 Node：
npx --yes serve . -l 8000
```

浏览器打开 **http://localhost:8000** —— 必须用 `localhost`，不要双击 `index.html`：

- 麦克风权限只在安全上下文可用，`localhost` 算，`file://` 不算；
- ES 模块在 `file://` 下会被浏览器拦住，页面直接白/黑。

## 三、断网检查（30 秒）

1. 笔记本关掉 Wi-Fi（或拔网线），只留本机。
2. 刷新 `http://localhost:8000`，应仍是开始页。
3. 点「开始」→ 校准 → 能听到左/前/右三声 → 说明音频与素材都在本地。

**为什么敢断网**：项目零依赖、无构建步骤、台词全部预渲染入库。运行时唯一会 fetch 的是本机的 `content/` 与 `assets/`。

## 四、每局流程（给志愿者的一页话术）

1. 「请戴上耳机，两边都戴好。」→ 玩家点「左耳 / 右耳」自检。
2. 「屏幕是全黑的，这是设计的一部分。用 W 前进，A/D 转身，空格敲杖，按住 T 说话。」
3. 校准 30 秒：左、前、右各一声，问「听清了吗」。
4. 游戏中保持安静，不要提示方向；玩家卡住超过 1 分钟再轻声提示「可以敲一下手杖」。
5. 结算后问一句：「刚才哪一段最让你紧张？」——收集一句口述反馈。

## 五、故障处理

| 现象 | 原因 | 处理 |
| --- | --- | --- |
| 打开是文件列表 | 服务器起在了上一级目录 | `cd` 回能看到 `index.html` 的那层 |
| 页面全黑、控制台报 CORS | 用 `file://` 打开了 | 改用 `http://localhost:8000` |
| 没有声音 | 浏览器未解锁音频 / 系统静音 / 输出设备错 | 先在页面上点一下；检查音量与输出设备；换耳机 |
| 麦克风无反应 | 权限被拒 / 非 Chrome·Edge | 地址栏小锁里允许麦克风；换 Edge |
| 语音一直听不懂 | 环境太吵 | 让玩家用键盘或按钮面板，这是设计内的降级 |
| 台词不播 | 素材缺失 | 看控制台 `[T5] 台词文件缺失`；重启服务；确认 `assets/voice/` 完整 |
| 页面卡顿 | 后台标签页被节流 | 保持窗口在前台，关闭其它标签 |

## 六、收场

- `git status` 确认没有把现场产生的临时文件带进仓库。
- 把当天玩家口述反馈补进 `docs/test-log.md`（日期 / 设备 / 现象 / 据此改了什么）。
- U 盘里的离线包与仓库保持一致（重新打包一次）。
