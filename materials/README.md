## 二、展板文案（只有两句话）

> **一条两百米的上学路，他们要用手杖和耳朵走五分钟。**
>
> **我们把它做成了只能用耳朵和嘴完成的游戏——你听不见的，就是他们看不见的。**

- 版式：纯黑底，白字，无图（与作品一致：屏幕全黑）。
- 右下角小字：`《盲盒校园：暗夜探险》· 戴上耳机，按空格开始`。
- 尺寸：80 × 180 cm，出血 3 mm；字体用思源黑体 Bold，正文 ≥ 60 pt，保证 2 米外可读。

## 三、演示视频分镜（3 分钟）

| 时间 | 画面 | 声音 / 字幕 |
| --- | --- | --- |
| 0:00–0:15 | 全黑，一行白字标题 | 校园环境声（车流、人群）渐入 |
| 0:15–0:35 | 玩家戴耳机，屏幕全黑，手放键盘上 | 字幕：屏幕全黑是设计的一部分 |
| 0:35–1:05 | 开始页 → 耳机检查 → 30 秒校准 | 「左」「前」「右」三声，玩家点头 |
| 1:05–1:45 | 游戏：W 前进、车流从右耳过、敲杖 | 现场同期声 + 旁白「他不知道前面有什么」 |
| 1:45–2:15 | **必须完整拍到**：玩家说「帮我读一下前方告示牌」→ AI 朗读 → 玩家说「向左走」 | 这句是作品的题眼，不能剪碎 |
| 2:15–2:40 | 自行车挡道 → 敲杖 → 绕行 → 回到盲道 | 任务完成音 + 台词「你绕过了自行车，又踩回了盲道」 |
| 2:40–2:55 | 结算页：用时 / 任务 3/3 / 敲杖次数 | 字幕打出数字 |
| 2:55–3:00 | 黑屏，一句话 | 「你听不见的，就是他们看不见的。」 |

拍摄注意：

- 录屏与实拍都要有声音，**不要把声音轨替换成 BGM**，这部作品的声音就是内容。
- 语音那一段用外接麦克风收，避免笔记本风扇声盖住指令。
- 导出 1080p / H.264，文件名 `盲盒校园_演示_20261126.mp4`。
